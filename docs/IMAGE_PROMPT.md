# Image-generation prompt

**Mode:** Built-in image generation

**Use case:** `ui-mockup`

**Asset type:** Image-generated product mockup for a university coursework packet.

Create a polished desktop browser interface mockup for a Mexican school emergency decision-rehearsal product called **Decisión Bajo Presión**. The product measures observable decisions rather than claiming preparedness.

Show a modern web dashboard whose main left panel contains a clean low-poly 3D school corridor during an earthquake rehearsal. The primary exit is visibly blocked by fallen ceiling panels, with a safe alternate-route sign. Include no injured people, panic imagery, fire, or death.

The adult teacher user is at Decision 2 of 3. A neutral voice-assistant indicator is active. Show three decision cards: **Usar salida bloqueada**, **Verificar ruta alterna**, and **Esperar instrucciones**. Include a small timer and the scenario label **Escenario B — retest no visto**. The right panel shows an observable evidence trace with timestamps, actions, and one item marked **Requiere prueba física**. Include the banner **IA simulada — la decisión final es humana** and a prominent **Pausar y salir** control.

Use a high-fidelity, straight-on, 16:9 SaaS interface in Spanish. The mood should be calm, serious, trustworthy, and accessible. Use deep navy, warm off-white, teal for safe actions, amber for unresolved evidence, and red only for the blocked-exit warning.

Do not include real personal data, recognizable victims, fear-adaptive content, readiness scores, courage scores, panic scores, survival probabilities, claims that lives are saved, real organization logos, or watermarks.
